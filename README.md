# ТехУчёт 2.0 — PHP + PostgreSQL

Веб-приложение для внутреннего учёта оборудования. Требует PHP 8.0+ (использует `match`, union types и `never`), расширение pdo_pgsql, PostgreSQL, Apache. **Версии пакетов Astra Linux Smolensk необходимо проверить локально.**

## Быстрый запуск
1. Создать PostgreSQL БД `techuchet`, отдельного пользователя с доступом к БД.
2. `psql -d techuchet -f database/schema.sql` от владельца схемы.
3. `cp config.example.php config.php`, заполнить параметры, выставить `chmod 640 config.php`, настроить владельца/группу.
4. `php scripts/create_admin.php admin 'Администратор' 'ВАШ_СЛОЖНЫЙ_ПАРОЛЬ'` (не оставляйте пароль в истории shell; лучше временно изменить скрипт на безопасный интерактивный ввод).
5. DocumentRoot Apache — только каталог `public/`. Включить HTTPS и закрыть доступ из внешних сетей.
6. Открыть сайт, войти под администратором.

## Ограничения этой версии
Рабочий исходный прототип, **не прошедший интеграционные испытания на Astra Linux**. Печатная форма HTML с `window.print()`, без встроенного PDF-архивирования; импорт CSV базовый (без визуального мастера и чтения цветов XLSX); массовое поступление доступно для уже созданных карточек через групповые операции, автоматическое создание новых карточек пачкой ещё не реализовано; роли фиксированы; печать использует зарегистрированную операцию; пользовательские метки не имеют отдельной истории удаления; нет автоматического создания задач возврата при увольнении; отсутствуют тесты и механизм обновления БД кроме исходной схемы. Не вводить в промышленную эксплуатацию до доработки и проверки безопасности, корректности движения, резервного копирования и прав доступа.

## Изменение накладной
`app/templates/transfer_v1.php` — разметка печати. Исторический снимок данных хранится в `documents.snapshot`, однако **старые документы используют текущую версию файла шаблона**: для гарантированного неизменного архива требуется реализация версионирования шаблонов и сохранения PDF. После изменения шаблона необходимо тестировать печать.

## Модули
`app/bootstrap.php` — общая инфраструктура, PDO, сессии, аудит; `app/movement.php` — групповые операции; `app/document.php` — документы; `public/index.php` и `public/extra.php` — маршруты и интерфейс; `database/schema.sql` — структура БД. В будущей версии разделить обработчики по контроллерам и добавить миграции.
